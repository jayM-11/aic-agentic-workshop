# Ideas for your-page.html

Pick one, mix two, or invent your own. Keep it plain HTML, CSS, and JS.

## 1. Member leaderboard
Rank members by points earned for attending events, shipping team features, or helping others. Add a data file like `data/members.js`, sort it with a tested function in `js/logic.js`, and highlight the top three.

## 2. AI tool of the week
Feature one AI tool each week with a short write-up, a "try it" link, and a tip from a member. Keep past picks in an archive list below the current one.

## 3. Event RSVP form
A form where members pick an upcoming event and enter their name and email. Validate the inputs with tested logic and show a confirmation message (no server needed; you can keep RSVPs in `localStorage`).

## 4. Hackathon countdown
A live countdown to the next club hackathon with days, hours, minutes, and seconds. Put the time math in `js/logic.js` so it can be tested with a fixed "now".

## 5. Resource library
A searchable list of tutorials, papers, and courses, tagged by topic like "RAG/LLMs" or "Computer Vision". Add a search box and tag filters that reuse the same matching rules as the teams page.

## 6. Officer directory
Cards for each club officer with their role, major, and what to ask them about. Add a short "office hours" line and a contact button for each one.
